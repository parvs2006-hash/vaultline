SECTION 5 OF 8 • CLOUD INFRASTRUCTURE

AWS Infrastructure Using Terraform

Networking & Security Groups

  • Region: AWS Asia Pacific Mumbai (ap-south-1).
  • Custom VPC (10.0.0.0/16) + Public Subnet (10.0.1.0/24) + Internet Gateway.
  • Security Group: Ingress Port 80 (HTTP) open to public; Ingress Port 22 (SSH) strictly restricted to authorized admin IP.

Compute & Encrypted Storage Tier

  • EC2 Instance: Amazon Linux 2023 on t3.micro with encrypted EBS root block volume.
  • IMDSv2 Enforced: http_tokens = "required" preventing SSRF credential theft.
  • S3 Audit Bucket: Object Versioning enabled, AES-256 Server-Side Encryption, and complete public access block.
Speaker Talking Points: "We provisioned the entire AWS cloud environment using Terraform. Rather than manual console configuration, our infrastructure is 100% reproducible through code. We configured an isolated VPC, restricted SSH access to our administrative IP, enforced IMDSv2 on our EC2 instance to prevent SSRF credential theft, and provisioned a versioned, AES-256 encrypted S3 bucket for banking audit storage."
