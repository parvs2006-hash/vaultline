🎯 Project Objectives

EduTrack is designed to address early academic attrition and attendance irregularity in higher education institutions. By integrating daily attendance tracking with multi-subject marks analysis, EduTrack provides faculty members with a real-time early warning system to support United Nations Sustainable Development Goal 4: Quality Education.

Early Risk Detection

Dynamically classifies students as At Risk or Needing Attention based on customizable attendance and score thresholds.

Strict Role Governance

Enforces complete server-side security isolating student data and preventing grade tampering via Spring Security 6.

Zero Database Dependency

Built using core Java memory collections (java.util.Vector) and robust CSV file persistence.

💻 Technology Stack

Java 17 (LTS) Spring Boot 3.2.5 Spring Security 6 (BCrypt) Thymeleaf Template Engine Chart.js 4.4 HTML5, CSS3 & Vanilla JavaScript Apache Maven 3.9
